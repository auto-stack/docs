## 编译器技术资料

### 入门书籍

- [Crafting Compilers](https://www.craftinginterpreters.com/introduction.html) - 入门必读！实现了两个解释器，一个Java版本的直接解释器，另一个C版本的ByteCode解释器。
- [Writing an Interpreter in Go](https://interpreterbook.com/) - Go语言实现一个解释器。
- [Writing a Compiler in Go](https://compilerbook.com/) - Go语言实现一个编译器（其实还是解释器，带VM）。

上面这两套书是我个人认为入门编译器技术的必读之作。
