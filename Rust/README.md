
教程

入门教程
- [Rust Book](https://doc.rust-lang.org/book/) - 官方教程
- [Rust By Example](https://doc.rust-lang.org/rust-by-example/) - 实例合集，而且可以在线跑
- [Comprehensive Rust](https://google.github.io/comprehensive-rust/) - 谷歌Android团队编的教程
- [Rust语言圣经](https://course.rs/about-book.html) - 国人写的中文版的Rust教程
- [Rust语言入门教程](https://www.bilibili.com/video/BV1hp4y1k7SV/) - B站的视频教程，配套书就是上面的官方Rust Book
- [Rustlings](https://github.com/rust-lang/rustlings) - Rust语法的互动练习。对理解Rust的特殊特性非常有用!

进阶教程
- [Learn Rust the dangerous way](https://cliffle.com/p/dangerust/) - 面向C程序员的Rust底层开发教程
- [Rustonomicon](https://doc.rust-lang.org/nomicon/) - 讲述Rust很多特性的实现原理的进阶教程
- [Rust with too many lists](https://rust-unofficial.github.io/too-many-lists/) - 讲述了如何在Rust中实现各类数据结构的进阶教程
- [Rust the Performance book](https://nnethercote.github.io/perf-book/title-page.html) - 讲述Rust性能相关的进阶话题
- [Mini LSM](https://skyzh.github.io/mini-lsm/00-preface.html) - 一周内实现一个类似Redis的内存K-V库
- [Parsing basics](https://domenicquirl.github.io/blog/parsing-basics/)  - 用Rust写一个语法解析器
- [Rustc Dev Guide](https://rustc-dev-guide.rust-lang.org/getting-started.html) - Rust编译器的开发指南

嵌入式教程
- [The Embedded Rust Book](https://docs.rust-embedded.org/book/intro/index.html) - Rust嵌入式开发的官方开源书
- [Discovery](https://docs.rust-embedded.org/discovery/index.html) - 用具体的开发板（STM32-F3和micro:bit）介绍Rust嵌入式开发的入门教程
- [The Embedonomicon](https://docs.rust-embedded.org/embedonomicon/) - 从零开始开发一个#![no_std]的工程，偏重于底层
